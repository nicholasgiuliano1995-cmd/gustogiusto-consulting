# Gusto Giusto — Consulting

Premium multilingual (IT / ES / PT) B2B marketing site for Gusto Giusto: market-entry and commercial development consulting for the Russian market, aimed at wine and food producers.

**Stack:** [Astro](https://astro.build) + Tailwind CSS 4 + GSAP ScrollTrigger. Fully static output, self-hosted fonts (Cormorant Garamond + Inter), no external CDNs.

```bash
npm install
npm run dev       # local preview at http://localhost:4321
npm run build     # production build → dist/
```
